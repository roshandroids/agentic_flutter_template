[`.ai/AGENTS.md`](.ai/AGENTS.md). This root-level file exists because several
AI tools (and humans pasting context into ChatGPT/Gemini) auto-discover an
`AGENTS.md` at the repo root - it is a pointer, not a second copy. See
[ADR-0005](docs/adr/ADR-0005-ai-single-source-of-truth.md) for why there is
exactly one canonical file.
