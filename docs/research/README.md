# Research

Pre-implementation investigation for features with real design uncertainty
- not required for routine work. If a feature's approach is obvious from
existing patterns, skip straight to
[`../engineering/NEXT_TASK.md`](../engineering/NEXT_TASK.md) and
implementation; reserve a research doc for genuine unknowns (a new
integration, a performance-sensitive design, an ambiguous UX tradeoff).

## Convention

One file per research question: `RP-XXX-topic.md` with the question,
options considered, and a recommendation. If the recommendation becomes an
architectural decision, promote it to an ADR under
[`../adr/`](../adr/) - the research doc stays as the supporting
investigation, the ADR is the decision record.
