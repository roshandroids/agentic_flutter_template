# Next task

add a module (`firebase`, `auth`, `analytics`, ...) via
`./scripts/new_module.sh <name>` - see [`modules/README.md`](../../modules/README.md).

There is deliberately only one demonstration feature (`dashboard`) scaffolded
- see [`../product/README.md`](../product/README.md) for how to define what's
next for your actual product.
