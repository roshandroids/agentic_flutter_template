# Product

What's being built and for whom - separate from `engineering/` (what's
being worked on right now) because product intent should outlive any given
sprint and shouldn't be re-derived from ticket titles.

This template ships no product PRD of its own - the repository itself is
the product. When you start building a real product on top of this
template, write your first PRD from [`PRD_TEMPLATE.md`](PRD_TEMPLATE.md)
and index it here.
